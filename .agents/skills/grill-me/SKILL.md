# Grill-Me Skill

Interview the user relentlessly about every aspect of their proposed plan, design, or feature idea until reaching a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one-by-one.

## Guidelines
1. **One Question at a Time**: Ask questions one at a time, waiting for user feedback on each question before moving to the next.
2. **Include Recommendations**: For each question, provide a recommended answer or perspective based on best practices and the current codebase.
3. **Explore Codebase First**: Before asking the user to explain technical details, search and inspect the codebase to see if the answer already exists.
4. **Target Outcome**: Stress-test edge cases, user workflows, data models, state management, and architectural implications so the idea is completely resolved before moving to specification (`to-spec`).
